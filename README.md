# 🔍 KQL Detection Scripts

My personal collection of **KQL detection scripts** for identifying security threats and suspicious activities.

## 🎯 What's Inside

Custom detection queries I've created for:
- **Malicious activities** and attack patterns
- **Suspicious behaviors** and anomalies
- **Indicators of compromise** (IoCs)
- **MITRE ATT&CK** technique detection

## 📂 Categories

- **Threat Detections** - Specific threats and malware
- **Behavioral Detections** - Suspicious user/system behaviors  
- **Technical Detections** - Attack techniques and tools
- **Network Detections** - Malicious network activity
- **Endpoint Detections** - Suspicious processes and activities
- **Data Exfiltration** - Unauthorized data access/transfer

## 🚀 Usage

1. Review and customize for your environment
2. Test before deploying to production
3. Tune thresholds to reduce false positives
4. Deploy as analytics rules or manual queries
