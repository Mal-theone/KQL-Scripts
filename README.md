# 🔍 KQL Detection Scripts

Welcome to my personal collection of **Kusto Query Language (KQL)** detection scripts! This repository contains custom detection rules and queries that I've developed for identifying security threats and suspicious activities.

## 🎯 Purpose

This repository is a curated collection of **detection-focused KQL scripts** designed to:
- **Detect** malicious activities and security threats
- **Alert** on suspicious behaviors and anomalies  
- **Identify** indicators of compromise (IoCs)
- **Monitor** for specific attack patterns and techniques

Each script represents a unique detection capability that I've crafted based on threat intelligence, attack patterns, and real-world security scenarios.

## 📋 Repository Structure

The detection scripts are organized into focused categories for easy navigation:

### 🎯 **Threat Detections**
Scripts targeting specific threat actors, malware families, and attack campaigns

### 🛡️ **Behavioral Detections** 
Queries that identify suspicious user and system behaviors

### 🔧 **Technical Detections**
Scripts focused on specific techniques, tools, and tactics (MITRE ATT&CK mapping)

### 🌐 **Network Detections**
Queries for detecting malicious network activities and communications

### 💻 **Endpoint Detections**
Scripts targeting suspicious endpoint activities and processes

### 📁 **Data Exfiltration**
Detections for unauthorized data access and transfer activities

## 🚀 Using These Detections

1. **Review** the detection logic and comments in each script
2. **Customize** thresholds and parameters for your environment
3. **Test** thoroughly in a development environment first
4. **Deploy** as scheduled analytics rules or manual queries
5. **Tune** based on your environment's false positive rates

## ⚠️ Important Notes

- These are **custom detections** I've personally developed and tested
- Always **validate and tune** detections for your specific environment
- **Test thoroughly** before deploying in production
- Results may vary based on data sources and environment configuration

## 📖 Detection Methodology

Each detection script includes:
- **Description** of what the detection identifies
- **MITRE ATT&CK** technique mapping (where applicable)
- **Data sources** required for the detection
- **Tuning guidance** and threshold recommendations
- **False positive** considerations and mitigation strategies

---

*These detections represent my ongoing effort to improve threat visibility and security monitoring capabilities.*
